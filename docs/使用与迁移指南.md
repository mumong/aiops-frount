# AIOps Chat Widget — 使用与迁移指南

## 1. 概述

`aiops-chat-widget` 是一个可复用的 React 聊天组件，专为 K8s AIOps Copilot 后端（robusta）设计。它通过 SSE 流式协议与后端通信，实现了与终端 `curl` 命令完全一致的实时流式输出体验。

本指南覆盖两种使用方式：
- **独立运行**：作为独立前端项目启动，用于开发调试或独立部署
- **嵌入迁移**：作为子组件集成到其他 React 项目中，例如统一的运维管理后台

---

## 2. 本地启动（独立运行）

### 2.1 环境要求

- Node.js ≥ 18
- npm ≥ 9（随 Node.js 自带）
- 后端服务已启动（例如 `http://10.2.0.48:30800`）

### 2.2 启动步骤

```bash
# 1. 进入项目目录
cd frountind

# 2. 安装依赖（首次）
npm install

# 3. 启动开发服务器（绑定所有网络接口，方便本机浏览器访问）
npm run dev
```

输出示例：

```
VITE v6.x.x  ready in xxx ms

➜  Local:   http://localhost:5173/
➜  Network: http://10.2.0.48:5173/
```

### 2.3 修改后端地址

后端地址配置在 `vite.config.ts` 的 proxy 中：

```ts
proxy: {
  '/api': {
    target: 'http://10.2.0.48:30800',  // ← 改成你的后端地址
    changeOrigin: true,
    rewrite: (path) => path.replace(/^\/api/, ''),
  },
}
```

修改后重启 `npm run dev`。

### 2.4 浏览器访问

打开 `http://<VM_IP>:5173`（例如 `http://10.2.0.48:5173`）。

### 2.5 验证

- 输入框中输入 `我的集群有什么问题`
- 按 Enter 或点击发送
- 应看到 AI 推理过程实时流式显示，最终渲染为 Markdown 诊断报告

## 3. 迁移到其他 React 项目

ChatWidget 被设计为 **零依赖侵入** 的可嵌入组件。迁移有两种方式：

### 3.1 方式一：直接复制组件目录（推荐，最简单）

将 `src/components/aiops-chat/` 和 `src/hooks/useSSE.ts` 复制到你的项目中：

```
your-project/
└── src/
    ├── components/
    │   └── aiops-chat/         ← 复制整个目录
    │       ├── index.ts
    │       ├── ChatWidget.tsx
    │       ├── ChatWidget.module.css
    │       ├── ChatHeader.tsx
    │       ├── ChatHeader.module.css
    │       ├── MessageList.tsx
    │       ├── MessageList.module.css
    │       ├── UserMessage.tsx
    │       ├── BotMessage.tsx
    │       ├── MessageInput.tsx
    │       ├── MessageInput.module.css
    │       └── types.ts
    └── hooks/
        └── useSSE.ts          ← 复制此文件
```

然后在任意页面中使用：

```tsx
import ChatWidget from '@/components/aiops-chat'

function AiAssistantPage() {
  return (
    <div style={{ height: '100vh' }}>
      <ChatWidget
        apiBase="/api"          // 指向后端，或直接写完整 URL
        title="运维助手"
        placeholder="输入你的运维问题..."
      />
    </div>
  )
}
```

### 3.2 方式二：配置代理

如果你的项目也使用 Vite，在 `vite.config.ts` 中添加代理：

```ts
export default defineConfig({
  server: {
    proxy: {
      '/api': {
        target: 'http://10.2.0.48:30800',  // 你的后端地址
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/api/, ''),
      },
    },
  },
})
```

如果使用 Webpack 或 Create React App，在 `package.json` 中配置：

```json
{
  "proxy": "http://10.2.0.48:30800"
}
```

或者直接在后端开启 CORS（不推荐），这样 `apiBase` 可以直接写完整 URL：

```tsx
<ChatWidget apiBase="http://10.2.0.48:30800" />
```

### 3.3 依赖清单

组件自身依赖需要已安装在你项目中：

| 包 | 版本 | 说明 |
|---|---|---|
| `react` | ≥ 18.0.0 | 运行时 |
| `react-dom` | ≥ 18.0.0 | 运行时 |

组件**不需要**额外 UI 库（如 antd/mui），所有样式通过 CSS Modules 自包含，不会污染父项目样式。

### 3.4 类型安全

组件导出类型定义，父项目可直接使用：

```tsx
import ChatWidget, { type ChatWidgetProps } from '@/components/aiops-chat'

const config: Partial<ChatWidgetProps> = {
  apiBase: '/api',
  title: '我的助手',
  placeholder: '有什么可以帮你？',
  maxMessages: 100,
}
```

## 4. ChatWidget Props 参考

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `apiBase` | `string` | ✅ | — | 后端地址，如 `/api` 或完整 URL |
| `title` | `string` | ❌ | `K8s AIOps Copilot` | 标题栏文字 |
| `placeholder` | `string` | ❌ | `输入你的运维问题...` | 输入框占位文本 |
| `maxMessages` | `number` | ❌ | `50` | 消息列表最大条数 |

## 5. 组件交互说明

### 5.1 端点模式切换

用户可在顶部切换两种模式：

| 模式 | 对应端点 | 适用场景 |
|------|----------|----------|
| 🔍 诊断 | `/ask` | 分析原因、诊断故障 |
| 📊 查询 | `/query` | CPU/内存/状态等结构化查询 |

切换不影响流式渲染逻辑，两种端点返回相同的 SSE 事件格式。

### 5.2 流式输出

请求发出后，前端实时展示：

1. **打字机效果** — AI 推理文字逐字出现
2. **工具调用卡片** — 显示工具名称、执行状态和结果摘要
3. **节点进度标签** — 显示工作流各节点（问题定位/证据采集/根因分析/汇总总结）状态和耗时
4. **Markdown 报告** — 最终诊断报告完整渲染，包含表格、代码块、列表

### 5.3 停止请求

流式输出期间可点击 "⏹ 停止" 中断请求，底层会 `AbortController.abort()`。

## 6. 常见问题

**Q: 页面能打开但发送后无反应？**

检查浏览器控制台（F12 → Console）是否有跨域错误。确认 Vite proxy 配置正确，或直接给后端配置 CORS。

**Q: 流式输出中断或超时？**

后端诊断可能需要几分钟，属于正常行为。如果长时间无响应，检查后端服务是否正常运行：

```bash
curl http://10.2.0.48:30800/health
```

**Q: 如何适配深色模式？**

组件使用 CSS Modules，所有颜色值硬编码在当前样式中。如需支持深色模式，在 `*.module.css` 中各添加 `[data-theme="dark"]` 选择器对应的色值覆盖即可。

**Q: 如何修改 ChatWidget 的宽度/高度？**

组件会填满其外部容器。控制容器大小即可：

```tsx
<div style={{ width: 600, height: 400 }}>
  <ChatWidget apiBase="/api" />
</div>
```
